# Racing

A mobile-friendly arcade racing prototype built with Next.js, React, TypeScript and Canvas.

## Features

- Third-person, pseudo-perspective arcade racing view
- Touch-and-hold controls for steering, throttle and brake
- Keyboard support (arrow keys or WASD)
- Speed, current lap, last lap and best lap HUD
- Start, pause and reset controls
- Responsive layout for phones and desktop

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

This is an arcade prototype, not a physics-accurate simulator. Track rendering and lap timing are simplified for the first playable version.
